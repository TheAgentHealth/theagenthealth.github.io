AgentHealth v0.21.0

Phase 23 introduces explicitly authorized local executable adapters. Repeat --adapter manifest.json with check, ping or doctor to register an unclaimed target type. The host validates compatibility and metadata, checks executable SHA-256, starts each dimension without an inherited environment or shell, accepts bounded strict JSON events, and terminates checks on cancellation. The engine retains active opt-in, normalized health states, response-aware retry policy, dependency aggregation and all output/exit-code contracts.

See the guide, example, transport RFC and all-phase alignment.

Installation and distributions

All implemented distributions share v0.21.0: five CLI archives and SBOMs, DEB/RPM, channel manifests, Docker image, Helm chart, OCI binary bundle, Python SDK and JavaScript/TypeScript SDK. Follow installation and distribution verification. CLI and SDK versions must match. Helm uses chart 0.21.0, app version/image v0.21.0. Publication and public access are verified; see the verification record.

Compatibility and migration

No AHS/AHP v1 fields, target schema or built-in checks change. Existing target YAML cannot authorize executable loading. No migration is required for existing users. Executable manifests are a separate local operator choice; built-in ownership cannot be overridden through the CLI. External adapter executables are not bundled with the CLI, container, chart or SDKs.

Limitations

The transport forwards identity, endpoint, dimension and optional bearer credential only. Rich protocol configuration, persistent sessions, automatic discovery, downloads, SDK manifest APIs, AHP loading and community certification are absent. A process retains the invoking user's filesystem/network permissions. Hashes do not pin interpreter dependencies or prevent concurrent executable replacement in operator-writable directories. Unix process groups are terminated; other platforms only guarantee direct-child termination. OS sandboxing and real community adapter interoperability remain planned. The example is an UNKNOWN remote-health fixture.
