All-phase documentation status

This index follows the source-tree scope in ROADMAP.md. Phases 0–7 have released baselines; Phase 8 is released in v0.6.0; Phase 9 in v0.7.0. Phase 10 is included in v0.8.0; see the alignment audit. Phase 11 experimental HTTP serving is included in v0.9.0; see its coverage and alignment audit. Phase 12 Docker distribution is released in v0.10.0. Phase 13 package-channel tooling is included in v0.11.0. Planned phases have roadmap designs, not shipped adapters, packages or runnable integration examples. Existing repository CI and protocol interoperability tests do not establish completion of the broader Phases 21, 25 or 26.
