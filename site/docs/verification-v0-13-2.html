Attempt history and limits

v0.13.0 staging stopped when verification found stale embedded installation references. v0.13.1 staging failed because the PyPA action pin was an annotated tag object without a matching container image. Its infrastructure-only recovery then caught a macOS SDK cleanup race. Both immutable tags and staged artifacts are preserved; neither became a final GitHub or PyPI release. v0.13.2 fixes installation rendering, the publisher commit pin and cleanup, accepting a permission error only after confirming CLI exit.

The first Copilot review's reproducibility and stderr credential findings were addressed. No second review was requested or awaited. Final fixes were pushed to main under the maintainer's explicit authorization.

Native OS signing/notarization, Helm GPG .prov, APT/YUM repositories, public Homebrew/Scoop hosting and cloud-cluster certification remain deferred. Local ARM64 container execution was not tested; native ARM64 archive CI passed. Windows detached stdio descendants need external lifecycle controls. GitHub Packages has no Python registry: the wheel/source archive are ordinary GitHub Release assets and also included in the signed OCI file bundle.

Local verification reports are under /tmp/agenthealth-release-verification/v0.13.2; that temporary directory is not a public download channel.
