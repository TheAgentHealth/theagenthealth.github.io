v0.21.0 publication verification

Release: AgentHealth v0.21.0. Regular public Latest release; source commit ee6edbdc47731abe0cbffa8555dbaf90d081c389. No published tag was moved or replaced.

All 21 required release assets were downloaded anonymously and checked against published digests and the complete checksum manifest. Five platform archives, matching CycloneDX SBOMs, four DEB/RPM packages, channel manifests, Helm chart, Python wheel/sdist and npm tarball are present. Signed GitHub provenance was verified against the exact source SHA/tag for every asset; archive SBOM attestations were verified independently.

The Linux AMD64 archive was executed: version, HTTP health checks, canonical JSON, JUnit/GitHub and all four observability projections passed. Other platform archive contents/hashes were checked; CI provides their native runtime coverage.

PyPI wheel/sdist and npm registry tarball bytes, digests/integrity and provenance match the signed release artifacts. See the release workflow for the exact-tag pre-release CI gate and publication jobs.
