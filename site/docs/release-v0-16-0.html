AgentHealth v0.16.0

Phase 18 adds PostgreSQL, MySQL, Redis and MongoDB native database health. SQL passive checks establish login; explicit functional runs one fixed SELECT 1. Redis/MongoDB use authenticated PING. Verified TLS is the default; passwords resolve through environment references and engine redaction. URI credentials/options and arbitrary queries are rejected. Native probes share passive evidence per target run, honor deadlines and disable operation retries.

Both SDKs include the additive database configuration schema. Earlier phases retain their health states, v1 result/exit contracts, independent dependency policies and AHP freshness semantics. Kubernetes continues to use existing Secret injection, liveness/readiness separation and synchronized image/chart pins. See the all-phase review.

pip install agenthealth==0.16.0
npm install @theagenthealth/agenthealth@0.16.0
docker run --rm ghcr.io/theagenthealth/agenthealth:v0.16.0 version
helm upgrade --install agenthealth oci://ghcr.io/theagenthealth/charts/agenthealth \
  --version 0.16.0 --set-file config=./agenthealth.yaml

All implemented artifacts share immutable source tag v0.16.0: five CLI archives, five CycloneDX SBOMs, checksums, four Linux packages, Homebrew/Scoop manifests, Docker images, chart agenthealth-0.16.0.tgz, OCI download bundle, Python wheel/sdist and npm tarball. Downloads are attached to this Release. Verify checksums and GitHub attestations before installation.

  • Docker: ghcr.io/theagenthealth/agenthealth:v0.16.0 and configured Docker Hub mirror theagenthealth/agenthealth:v0.16.0.
  • Helm: oci://ghcr.io/theagenthealth/charts/agenthealth, version 0.16.0, appVersion: v0.16.0.
  • OCI bundle: ghcr.io/theagenthealth/agenthealth-binaries:v0.16.0, retrieved with ORAS.
  • Python: agenthealth==0.16.0; npm: @theagenthealth/agenthealth@0.16.0.

No breaking AHS v1/result/exit-code changes; older CLIs reject the new database options. Upgrade SDK and CLI together. Source-build Go minimum advances to 1.26 for security-patched native drivers and Unicode/cryptography dependencies; installed binaries require no Go or external database CLI. See the tagged go.mod for the exact minimum.

Controlled tests cover PostgreSQL 17.6, MySQL 8.4.6, Redis 7.4.5 and MongoDB 8.0.13 healthy probes and incorrect passwords. Application data permissions, replication freshness, broad server-version/TLS matrices, MongoDB topology/SRV, cloud/IAM authentication and vector retrieval remain outside this baseline. Minimal query success does not prove application read readiness.
