v0.14.0 publication verification

Verified on 2026-10-15. GitHub Release, PyPI and npm are public.

Source and publication

The immutable source tag is v0.14.0, commit 4993f41db99c340ad383c848e9ce86cd0944c3a1. The source release build produced the 21 signed assets. All assets were retained unchanged during infrastructure recovery, which completed successfully on its second attempt. The tagged-source CI passed, including native binary, Kubernetes and six JavaScript SDK matrix jobs.

The initial unpublished tag was recreated with explicit maintainer authorization. The final source tag has not moved after publication. Recovery corrected npm workflow identity and publication invocation; it did not rebuild release payloads. npm trusted publishing uses release.yml, environment npm, and OIDC without an npm token. Its registry provenance identifies infrastructure commit 8231d8aa337c8da2ff6ec7ae04d4a90d90524c9b on main; the published tarball exactly matches the signed artifact built from the source tag above. npm accepted the package before its registry metadata propagated; verification was rerun after propagation and skipped publication of the existing identical package. Future verification now waits up to ten minutes for registry propagation.

PR #50 was merged after green CI and the first Copilot review. All three valid findings were addressed; no second review was requested. Subsequent infrastructure and verification documentation changes were pushed directly to main as authorized.

Download integrity, contents and runtime

  • All 21 assets downloaded anonymously from the public release and matched the previously verified staging bytes and GitHub asset digests.
  • All 20 SHA-256 entries in signed checksums.txt matched.
  • All 21 build provenance attestations and five CycloneDX attestations verified against the exact source tag/commit and hosted release workflow.
  • Five platform archives passed safe-content, license, permissions, platform-header, executable/SBOM hash and Go 1.27.2 toolchain checks. Four DEB/RPM packages matched their archive binaries, platform/version metadata and certificate dependencies, without installation hooks. Homebrew/Scoop URLs, versions and hashes matched.
  • Downloaded Linux AMD64 CLI passed version/help, health exit codes 0–5, tool failure exit 6, JSON/YAML validation, ping/doctor, AHP authentication, capabilities/dependencies, graceful shutdown and credential redaction checks.
  • Public PyPI wheel and sdist matched signed release bytes; PyPI attestations verified. A fresh public installation passed 15 SDK integration tests against the downloaded CLI.
  • Public npm installation passed native Linux CLI invocation. All seven installed dependency registry signatures and the SDK provenance attestation verified with npm audit signatures. Public tarball bytes and SHA-512 integrity matched the signed release tarball. Installed tarball ESM and TypeScript smoke checks passed.

Limits

Local runtime verification used Linux AMD64. Other platform binaries were checked by archive inspection and native CI; local ARM64 execution is not claimed. Executable OS signing, macOS notarization, Helm GPG signing, APT/YUM repositories, and managed Homebrew/Scoop repositories remain outside this release. Windows SDK cancellation terminates the direct CLI process; POSIX process-group cleanup has broader descendant coverage. SDK installation does not download a CLI binary.
