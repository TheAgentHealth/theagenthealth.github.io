AgentHealth v0.19.0

Phase 21 adds CI/CD deployment validation: safe JUnit/GitHub report formats, a reusable GitHub Action, verified exact-version binary installation and shell, GitLab, Jenkins and Azure DevOps examples. All non-healthy statuses block promotion; health exit codes 0–5 and tool failure 6 remain distinct.

Compatibility and limitations

Existing v1 configuration/results, SDK JSON APIs, aggregation and active-check opt-in are unchanged. CI reports omit target names and diagnostic text, retaining positional dependency occurrences and statuses. JSON/YAML remain authoritative for detailed evidence. The Action requires an installed verified CLI, Python 3.10+ and Bash. Hosted GitLab/Jenkins/Azure matrices and SARIF remain deferred. See the guide, examples and Phase 0–26 alignment review.

Installation and synchronized distribution

The release requires all implemented formats under the same source tag: five CLI archives/SBOMs, Linux DEB/RPM, channel manifests, Docker, Helm, OCI binary bundle, Python wheel/sdist and npm tarball. Verify checksums and signed provenance using the distribution guide.

python3 scripts/install_ci_binary.py v0.19.0 ./agenthealth
./agenthealth check deployment.yaml --format junit > agenthealth-junit.xml
pip install agenthealth==0.19.0
npm install @theagenthealth/agenthealth@0.19.0
docker run --rm ghcr.io/theagenthealth/agenthealth:v0.19.0 version
helm install agenthealth oci://ghcr.io/theagenthealth/charts/agenthealth --version 0.19.0
oras pull ghcr.io/theagenthealth/agenthealth-binaries:v0.19.0

Matching manifests, chart source and Kubernetes examples use CLI/image v0.19.0. The chart archive is agenthealth-0.19.0.tgz in the release downloads. Kubernetes CI covers 1.31.9, 1.32.2 and 1.33.1; execution results and public distribution verification must be recorded after publication. GPG Helm .prov files are not supplied; use keyless GitHub attestations.

Publication verification

Synchronized publication and public installation checks passed. See the verification record for CI, source binding, signed assets, registry digests and actual runtime validation scope.
