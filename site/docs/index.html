Documentation guide

See the all-phase status index for implementation, documentation, and example coverage across Phases 0–26.

Phases 0–6 and foundation stabilization are implemented in v0.4.0. The specification remains pre-1.0. Use this index to find the current contracts, behavior, and examples; see the roadmap for limitations and later phases.

Phase Documentation Examples or supporting files
0: Foundation Architecture, contributing, governance, security policy, releases CI, installation
1: Specification Specification index: health states, target model, configuration, results, exit codes, adapter contract, security Schema fixtures and marked examples in the specification
2: Engine Core API and execution guarantees Go API example, configuration
3: CLI Commands, formats, doctor, OAuth login, and exit codes, installation Run the CLI, example commands
4: HTTP/API Status, headers, bearer authentication, body checks, transport diagnostics, and safety, HTTP configuration HTTP readiness, complete configuration examples in the specification
5: MCP HTTP/stdio, protocol selection, inventories, OAuth, functional probes, and limits, login Discovery, stateless, stdio, functional, and all OAuth flows
6: A2A A2A 1.0 JSON-RPC with explicit 0.3.0 compatibility discovery, authentication, skills, and opt-in interactions A2A v1 configuration, 0.3.0 compatibility
7: Agent health (v0.5.0) Health resource, capabilities, safe tasks and runtime handler prerequisites, impact proposal Agent, peer and path example
8: Agentgateway (v0.6.0) Gateway signals and backend/path evidence, impact proposal Gateway configuration
9: Agent Router (v0.7.0) Router signals and route/backend evidence, impact proposal Router configuration and setup
10: Dependency graph (v0.8.0) Shared nodes, edge policies and budgets, impact review Graph configuration, earlier-phase alignment
11: AHP (experimental, v0.9.0) HTTP serving, wire contract, impact review Serving example, coverage and alignment
12: Docker (v0.10.0) Docker distribution, container usage Dockerfile, CI container job, release publish job
13: Standalone binaries (v0.11.0) Package installation, coverage and alignment Distribution example, package builder, native smoke checks
14: Kubernetes (released chart 0.1.0) Deployment guide, coverage and alignment Manifests, Helm chart, scenarios, tests

Phase 7 is released in v0.5.0: see the agent adapter and agent/peer/path example.

Phase 10 is included in v0.8.0; older v0.7.0 binaries do not include it. Experimental AHP HTTP serving is included in v0.9.0; see AHP. Phase 12 — Docker Distribution is released in v0.10.0; see Docker.

Configuration examples are templates requiring your services and credentials. The documentation validator checks marked configuration/result blocks and standalone health configuration examples and configuration embedded in Kubernetes resources against the AHS schema; Helm overrides use the chart schema. Kubernetes manifests and chart rendering also have dedicated tests. Validation does not establish connectivity to the placeholder servers or prove every command example works.

Agent/multi-agent, gateway/router HTTP signals, HTTP/API, MCP, and A2A 1.0 JSON-RPC with explicit 0.3.0 compatibility are the available adapters. Other adapter types, SDKs remain planned; Kubernetes integrations and chart 0.1.0 are released (guide); a container image is published starting in v0.10.0. Historical release notes describe their tagged release. Use v0.2.0 or newer for Phase 5 MCP functionality and v0.3.0 or newer for Phase 6 A2A functionality.

Foundation stabilization in v0.4.0 adds current A2A, shared probes and release hardening. See interoperability and v0.4.0 migration notes.

Phase 8 Agentgateway integration is released in v0.6.0. See the gateway guide. Gateway checks use explicitly configured read-only HTTP signals and separate backend/path dependencies.

Phase 9 Agent Router HTTP integration is released in v0.7.0. See the router guide. Named router signals, direct backends and configured paths retain separate evidence.

Phase 9 release and migration details: v0.7.0 notes.

Phase 11 release and migration details: v0.9.0 notes.

  • Kubernetes integration — manifests, chart, probes, Secrets and deployment validation.
  • Phase 14 alignment — coverage, compatibility and validation limits.
